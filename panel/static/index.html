Параметры создания бэкапа

При запуске будет подключен удаленный VPS и создан сжатый архив рабочих конфигураций и БД (3x-ui, caddy, nginx, docker-compose). Архив будет скачан в локальную папку ./backups_panel/.

Параметры восстановления сервера из бэкапа

Архив бэкапа будет загружен на целевой сервер, распакован и запущен через Docker Compose. В случае изменения доменного имени автоматически обновится конфигурация Caddy и 3x-ui. Домен внутри панели 3x-ui перезаписывается через её HTTP API — для этого укажите логин и пароль админа из исходного бэкапа (по умолчанию admin/admin).

Параметры обновления 3X-UI панели

При запуске на удаленном сервере будет автоматически выполнен бэкап (panel_backup.sh), обновлен тег образа Docker в working/docker-compose/docker-compose.yml и перезапущен контейнер 3xui.

Перезапуск панели 3X-UI

При запуске на удаленном сервере будет выполнена команда перезапуска контейнера с панелью.

Перезагрузка сервера

При запуске на удаленном сервере будет выполнена команда reboot.

Перезапуск Сервера подписок

При запуске на удаленном Сервере подписок будет выполнена команда docker compose down/up (контейнеры subs-server и sub-caddy).

Обновление Сервера подписок

При запуске будет создан полный бэкап конфигурации в локальную папку ./backups_sub_server/, после чего файлы Сервера подписок будут обновлены и контейнеры subs-server и sub-caddy пересобраны (docker compose up -d --build). Клиенты, ноды и overrides будут сохранены.

Бэкап Сервера подписок

При запуске будет создан архив конфигурации Сервера подписок (nodes.json, force-subs.yml, Caddyfile, docker-compose, caddy_data) и скачан в локальную папку ./backups_sub_server/.

Восстановление Сервера подписок из бэкапа

Архив будет загружен на Сервер подписок, распакован в рабочую директорию, после чего контейнеры будут перезапущены.
